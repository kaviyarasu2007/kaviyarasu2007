### 🔍 Assessment & Triage Methodology

<details>
<summary><b>👉 Click to expand full Bug Hunting & Pentesting Workflow</b></summary>
<br/>

```
  [1. Scope & Recon] ───> [2. Surface Mapping] ───> [3. Deep Vulnerability Analysis]
         │                          │                               │
         ▼                          ▼                               ▼
  Passive DNS / OSINT       Endpoint Enumeration            Business Logic Testing
  Cert Transparency         Tech Stack Discovery            Authentication & Authz
  JS Code Auditing          Parameter Discovery             API & Input Fuzzing
                                                                    │
  [5. Remediation Advisory] <─── [4. PoC & Impact] <────────────────┘
         │                               │
         ▼                               ▼
  OWASP / NIST Guidelines         Minimal Impact Reproducible PoC
  Fix Verification & Triage       Actionable Severity Rating (CVSS)
```

1. **Reconnaissance & Asset Discovery:** Comprehensive passive DNS gathering, ASN mapping, subdomain aggregation, and continuous certificate transparency monitoring.
2. **Attack Surface Mapping:** Fingerprinting underlying web frameworks, dissecting compiled JavaScript client bundles, and identifying hidden API routes.
3. **Vulnerability Analysis:** Deep assessment focused on high-severity vulnerabilities—prioritizing business logic flaws, access control failures, and server-side request forgery.
4. **PoC Construction:** Developing concise, verifiable proof-of-concept demonstrations with zero unintended collateral damage.
5. **Responsible Disclosure:** Generating clean, actionable triage reports complete with CVSS scoring, root-cause diagnostics, and remediation recommendations.
